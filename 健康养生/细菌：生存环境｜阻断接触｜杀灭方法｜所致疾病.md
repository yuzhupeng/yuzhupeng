# 细菌：生存环境｜阻断接触｜杀灭方法｜所致疾病
> 底层第一性原理：细菌是单细胞原核生物，存活必须满足**水、适宜温度、营养、氧气条件**；杀灭本质就是破坏细胞结构/剥夺生存条件；预防就是切断它从「储存环境」到「人体定植位点」的传播通路。
> 分组：革兰阳性、革兰阴性、厌氧芽孢菌、抗酸特殊菌；每一类统一4栏：**生存环境｜避免接触｜杀灭方式｜引发疾病**

## 一、革兰阳性菌（G+，厚肽聚糖细胞壁）
### 1. 金黄色葡萄球菌
✅ 生存环境
广泛存在：**人的皮肤、鼻腔、毛发；空气、灰尘**；喜欢温暖（20–37℃）；可在含盐/含糖食物存活；重点：**它产生的肠毒素耐热，细菌能被煮熟，但毒素100℃加热杀不掉**。
✅ 避免接触
- 皮肤伤口包扎；手有化脓不要接触食物；不要反复常温放置熟食、奶油蛋糕、卤肉、剩米饭；不要用脏手抠鼻子后处理食材。
✅ 杀灭细菌本体
75%酒精、含氯消毒剂有效；煮沸10分钟杀死活菌；**⚠️ 毒素无法靠煮沸去除，变质食物直接丢弃**。
✅ 所致疾病
皮肤：疖、痈、伤口化脓；食物中毒（呕吐为主）；肺炎、心内膜炎、败血症；烫伤样皮肤综合征。

### 2. A族溶血性链球菌（化脓链球菌）
✅ 生存环境
**人体咽喉、皮肤黏膜**；飞沫/皮肤分泌物传播；在潮湿物品（毛巾、衣物）短期存活；不耐干燥。
✅ 避免接触
咽痛患者戴口罩；不共用牙刷、毛巾；皮肤破损做好防护，避免接触感染者伤口渗液。
✅ 杀灭
75%酒精、含氯消毒剂；煮沸快速杀灭；青霉素高度敏感。
✅ 所致疾病
扁桃体化脓、咽炎；丹毒、蜂窝织炎；猩红热；风湿热、肾小球肾炎（免疫继发损伤，不是细菌直接攻击肾脏）。

### 3. 李斯特菌（冰箱杀手）
✅ 生存环境
土壤、污水、动物肠道；**可在4℃冰箱低温持续繁殖**；耐盐，熟食、软奶酪、冷藏即食肉类、烟熏鱼容易污染。
✅ 避免接触
孕妇、老人、免疫弱人群不吃长期冷藏即食熟食；冰箱定期清洁；熟食不要在冰箱存放超过3–5天。
✅ 杀灭
**70℃以上加热即可杀灭**；含氯消毒剂、酒精有效；冷藏只能减缓，不能杀死。
✅ 所致疾病
肠胃炎；高危人群：败血症、脑膜炎；孕妇感染会流产、死胎、新生儿感染。

## 二、革兰阴性菌（G-，薄肽聚糖+外膜，自带内毒素）
### 1. 大肠埃希菌（大肠杆菌）
✅ 生存环境
**人和动物大肠肠道**；粪便污染水源、蔬果、肉类；潮湿环境存活久；兼性厌氧，有氧无氧都能活。大多数菌株共生无害，致病株（O157等）有毒力因子。
✅ 避免接触
生熟分开；蔬果清洗；肉类彻底煮熟；便后洗手；不要喝生水；尿道：如厕从前向后擦拭，避免肠道细菌污染尿道口。
✅ 杀灭
煮沸立刻杀灭；酒精、84有效；不耐高温。
✅ 所致疾病
普通型：急性肠胃炎；O157:H7：出血性肠炎、溶血尿毒综合征；尿路感染（最常见）；腹腔感染、败血症。

### 2. 沙门氏菌
✅ 生存环境
家禽、鸡蛋、畜禽肠道；粪便污染；生鸡蛋、生鸡肉是高风险；室温快速增殖，冷藏可存活但增殖变慢。
✅ 避免接触
鸡蛋、禽肉全熟；蛋壳不要接触其他食材；生熟砧板刀具分开；不生吃溏心蛋。
✅ 杀灭
70℃以上加热灭活；含氯消毒剂可环境消杀。
✅ 所致疾病
急性肠胃炎（发烧、腹痛腹泻）；少数菌血症。

### 3. 志贺菌（痢疾杆菌）
✅ 生存环境
患者/带菌者粪便；污染水源、瓜果；在潮湿食物存活数天，抵抗力偏弱。**传染性极强，少量细菌即可致病**。
✅ 避免接触
饭前便后洗手；不生吃路边瓜果；饮用水消毒；隔离腹泻患者粪便。
✅ 杀灭
煮沸；含氯消毒液；对酒精敏感。
✅ 所致疾病
细菌性痢疾：腹痛、里急后重、黏液脓血便。

### 4. 铜绿假单胞菌（绿脓杆菌）
✅ 生存环境
**潮湿潮湿潮湿！** 水池、地漏、湿抹布、加湿器、水管、潮湿创面；喜欢水环境，营养要求极低，少量水就能活；天然多重耐药。
✅ 避免接触
抹布、海绵不要长期潮湿；定期清洗加湿器；伤口不要长期浸泡积水；医院潮湿设备重点防控。
✅ 杀灭
普通酒精效果一般；优先**含氯消毒剂**；干燥环境会快速失活。
✅ 所致疾病
伤口感染、烧伤创面感染；中耳炎；肺炎（呼吸机相关）；尿路感染。

### 5. 霍乱弧菌
✅ 生存环境
淡水/咸水水域；水体被粪便污染；在咸水环境存活更久。
✅ 避免接触
不喝生水；不吃生腌、生水浸泡海鲜；水源消毒。
✅ 杀灭
煮沸；含氯消毒水体。
✅ 所致疾病
霍乱：剧烈水样腹泻，严重脱水休克。

## 三、厌氧芽孢菌（G+，可形成芽孢，重点难点）
> 第一性：**繁殖体怕热；芽孢极强抗性，普通煮沸杀不死**；芽孢只是休眠体，进入缺氧环境才萌发成活菌致病。

### 1. 破伤风梭菌
✅ 生存环境
土壤、尘土、动物粪便；**芽孢广泛存在于泥土、铁锈、灰尘**；只能在**深、窄、缺氧坏死伤口**萌发（钉子扎伤、穿刺伤，伤口闭合，氧气进不去）。
✅ 避免接触
外伤：深穿刺伤口充分敞开冲洗；及时评估破伤风疫苗；泥土脏污伤口不要封闭包扎。
✅ 杀灭
**繁殖体：煮沸可杀；芽孢：121℃高压蒸汽灭菌才能可靠灭活**；常规酒精、84对芽孢效果有限。
✅ 所致疾病
破伤风：神经毒素，肌肉强直性痉挛，可窒息死亡；**细菌不扩散，毒素入血致病**。

### 2. 肉毒梭菌
✅ 生存环境
土壤；厌氧密闭环境：自制发酵罐头、真空密封食品、自制腌菜；无氧常温，芽孢萌发产肉毒毒素（已知最强毒素）。
✅ 避免接触
家庭自制罐头必须高压灭菌；真空包装食物如果胀罐直接丢弃；不要吃可疑自制发酵食品。
✅ 杀灭
芽孢需高压蒸汽；**肉毒毒素80℃加热10分钟即可破坏**。
✅ 所致疾病
肉毒中毒：神经麻痹，视物模糊、吞咽困难、呼吸麻痹致死。

### 3. 产气荚膜梭菌
✅ 生存环境
土壤、动物肠道；深部缺氧创伤；腐败肉类。
✅ 避免接触
深部伤口清创，去除坏死组织；肉类不要常温久放。
✅ 杀灭
繁殖体易被杀灭；芽孢需高压灭菌。
✅ 所致疾病
气性坏疽（创伤深部感染）；食物中毒。

## 四、特殊抗酸菌：结核分枝杆菌
✅ 生存环境
肺结核患者飞沫；干燥痰液里可存活数月；耐干燥，对普通消毒剂抵抗力高于一般细菌；喜欢低氧的肺组织。
✅ 避免接触
活动性结核戴口罩；房间通风（通风是性价比最高手段，稀释气溶胶）；不随地吐痰。
✅ 杀灭
紫外线有效；含氯消毒剂长时间接触；**普通75%酒精需要较长作用时间；煮沸10分钟可杀灭**；单纯日晒效果有限。
✅ 所致疾病
肺结核；骨结核、肾结核等肺外结核。

# 汇总通用规律（提炼第一性推论）
1. **潮湿 = 绝大多数普通细菌天堂；干燥是低成本抑菌手段**（葡萄球菌耐受干燥，是例外）
2. **芽孢菌单独一套标准：日常消毒只能杀活菌，芽孢必须高压蒸汽**；伤口防破伤风重点不是杀环境芽孢，而是**破坏伤口缺氧环境+疫苗**
3. **低温冷藏 ≠ 杀菌，仅抑制；李斯特菌例外，冰箱里继续繁殖**
4. **毒素和细菌本体要分开看待：有些细菌死了，毒素还在，依然致病（金葡肠毒素、G-内毒素）**
5. 传播路径归类
    - 粪口：大肠杆菌、沙门、志贺、霍乱 → 洗手+饮水食物煮熟
    - 飞沫呼吸道：链球菌、结核 → 口罩+通风
    - 伤口/环境接触：金葡、绿脓、破伤风 → 伤口清创、保持干燥、脏环境消毒
