基础1：命令行基础知识
掌握如何通过命令行界面 (CLI) 进行导航、管理文件和运行脚本，会让你比大多数初学者更快。
 
 
 
 
基础知识 2：版本控制（Git）
这是必须的。
每个严肃的项目 → Git + GitHub。
你的代码仓库就是你的工作量证明。
 
 
 
 
基础知识3：人脉网络入门
了解 IP 地址、DNS 服务器、端口和防火墙。
无论是 AWS、Python 还是 DevOps → 一切都取决于网络。
 
 
 
 
基础四：数据库
SQL 基础知识：CRUD、连接、索引。
即使是简单的知识也能让你与只会做教程的程序员拉开差距。
 
 
 
 
第五大要点：API
学习如何使用 Python（requests）发送/接收数据。
API 连接一切——应用程序、云、自动化。
 
 
 
 
基础6：云基础知识
了解应用程序在云端实际运行的方式：EC2、S3、IAM、VPC。
即使是初级水平，这也是一项职业优势。
 
 
 
 
基本原则七：解决问题的思维模式
不要只问“语法是什么？”
问“我该如何分解这个问题？”
这就是你价值所在。
 
 
 
 
包起来
工具会改变。
框架将会改变。
但基本面会不断累积。
